# Feature matrix
## Implemented foundation
Database schema, Flyway ordering, DB-backed security model, employee DTO API, pagination, score calculation, certification status, token hashing, notification idempotency primitive, Excel validation primitive, health endpoint, Docker, CI, Railway config, core glass UI.
## Partially implemented
Course management, assignments, planning, scheduling, attendance correction/audit integration, notification workers, Telegram adapter, import transaction workflow, reports, role-scoped dashboards.
## Not yet complete
Full CRUD UI for every module, actual Telegram update handler and outbound sender, production Excel mapping wizard, PDF/Excel report rendering, end-to-end lifecycle test, original Python-bot migration, live Railway deployment.
