# Security
Authentication loads users, roles and permissions from PostgreSQL. Passwords must be BCrypt hashes. No default account is created. For first deployment, generate a BCrypt hash offline, insert one user in a controlled Railway database session, assign SUPER_ADMIN, then rotate the initial password immediately. Do not place the password or hash in migrations. Telegram raw link tokens are shown once, stored only as SHA-256 hashes, expire, and must be consumed transactionally. The current token primitive still requires persistence/consume endpoints before production use.
