# Exact Railway variables
Required: SPRING_PROFILES_ACTIVE=prod, DATABASE_URL, DATABASE_USERNAME, DATABASE_PASSWORD, APP_TIMEZONE, PUBLIC_BASE_URL. Optional/tunable: DB_POOL_SIZE, COOKIE_SECURE, TELEGRAM_ENABLED, TELEGRAM_BOT_TOKEN, TELEGRAM_BOT_USERNAME, TELEGRAM_WEBHOOK_SECRET, TELEGRAM_LINK_TOKEN_TTL, REMINDER_DAYS_BEFORE, REMINDER_HOURS_BEFORE, REMINDER_FINAL_HOURS_BEFORE. PORT is injected by Railway. Telegram secrets are required only when TELEGRAM_ENABLED=true.
